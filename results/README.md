# results/

Everything a run produces, plus the written findings.

```
results/
  raw/                       # GENERATED by run_probe.py — do not hand-edit
    <provider>/<model>/<question-id>/
      straight.json  straight.md
      analytical.json  analytical.md
  index.jsonl                # GENERATED — append-only manifest, one record per call
  synthesis/                 # HAND-WRITTEN — the findings live here
    FINDINGS.md
    EXPECTATIONS_AND_SURPRISES.md
    MODEL_DIVERGENCE.md
    HOW_THEY_ARE_NOT_HUMAN.md
```

**Rule of thumb:** `raw/` and `index.jsonl` are machine output — regenerate them
by re-running, never edit by hand. `synthesis/` is human writing and is the actual
deliverable.

`raw/` can get large (400 calls × full prompts + responses). To keep it out of
git, uncomment the relevant lines in `.gitignore` — the `synthesis/` files are
meant to be committed either way.
